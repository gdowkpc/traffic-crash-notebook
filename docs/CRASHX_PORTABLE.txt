CRASHX IDAHO - PORTABLE WINDOWS APP

START
1. Extract the entire CrashX folder to a writable location.
2. Open CrashX.exe.
3. Enter the crash and officer information.
4. Add any number of vehicles and people. A person can have one or more roles:
   driver, registered owner, passenger, witness, pedestrian, or bicyclist.
   Associate each driver and registered owner with the correct vehicle. Plate,
   plate-state, VIN, insurance-company, and policy-number entries automatically
   format as uppercase.
5. In Add person, select Scan license to read the PDF417 barcode with a connected
   camera. Fill the dashed guide with the barcode, not the entire license, hold it
   steady, and tilt the card slightly if there is glare. Review every filled field
   before saving the person. Manual entry remains available when a license or camera
   is unavailable.
6. Use Associated vehicle when the person belongs with a vehicle.
7. Select Save PDF and choose where the completed report should be written.

NO INSTALLER OR ADMINISTRATOR RIGHTS
The application runs from the extracted folder. It does not install a service,
write to Program Files, or request administrator elevation. Keep every file in
the extracted CrashX folder together.

DISPOSABLE DATA
The application does not create or update a case database. Entered crash,
vehicle, and person information exists only in the running application. Closing
the application or selecting Clear all discards that information. The PDF you
explicitly save is the only retained work product.

LICENSE SCANNING PRIVACY
Camera frames and the raw driver-license barcode payload are not written to disk.
Only mapped values placed in the open person form remain in memory for review.

PDF CONTENT
The report creates as many continuation pages as needed and appends an Idaho
information/responsibilities page. It is an involved-party exchange sheet, not an
official Idaho Vehicle Collision Report (IVCR), and does not determine fault.
Review the finished PDF and follow agency policy before printing or emailing it.

SELF-TEST
The packaged executable supports a non-interactive fictional-data self-test for
release verification. Normal users do not need to run it. Officers evaluating the
beta should also follow docs/IDAHO_FIELD_TEST.md and avoid sharing real personal
information in feedback.
